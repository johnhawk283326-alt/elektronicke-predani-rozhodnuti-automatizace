# elektronicke-predani-rozhodnuti-automatizace
Nástroj pro automatické vyplňování online formuláře Celní správy ČR
Program načte PDF soubor, vygeneruje xml soubor který lze načíst přes online formulář CS
Postup : načít pdf, stisknout vygenerovat xml soubor, tento pak uložit. Po uložení otevřít online formulář a uložený soubor do něho načíst
